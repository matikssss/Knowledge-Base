- Git - это **система контроля версий**. Для чего: упростить разработку.
- Основные задачи Git:
	- Сохранять историю изменений (отслеживание изменения в файлах и сохранения их версий)
	- Доработка функционала изолировано
	- Безопасно работать с кодом вместе с командой (создание веток для параллельной работы, объединение изменений разных разработчиков, при необходимости возврат к любой предыдущей версии проекта)
В Git живут конфигурации серверов, описания инфраструктуры Terraform, сценарии автоматизации, настройки CI/CD и документация.
## Три основные зоны внутри ПК
Рабочий каталог ── git add ──> Индекс ── git commit ──> Локальный репозиторий
## Три основные зоны внутри ПК + удалённый сервер
Рабочий каталог → Индекс → Локальная ветка → origin/main → Удалённый репозиторий


**Удалённый репозиторий** (remote) — это копия вашего репозитория на сервере. Он решает сразу несколько задач:

- **Резервная копия** — проект хранится не только у вас.
- **Совместная работа** — другие люди могут клонировать проект, вносить изменения и отправлять их обратно.
- **CI/CD** — автоматическая сборка и тестирование
